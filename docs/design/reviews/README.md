- 「剧情里面太无聊了一直去打徽章，然后其实剧情要有学习怎么玩这个游戏去引导，然后前期快速去打 DeepSeek 这个boss吧，引导全程怎么去打这个boss，就一开始的剧情，后面其实也同理很多boss都需要有引导和对应的剧情支撑以及对应的人物对话和交流还有小剧情，为了给用户早期的爽感 DeepSeek 这个boss是早期用户最快可以得到的高级boss卡，一般boss打败之后可以去进行捕捉，捕捉成功之后默认从1级开始，然后boss这边需要去凹属性，boss本身也是一个副本，得到的属性随机，其实大世界所有的模型属性都可以随机的，这样有凹属性的乐趣，可以去提高可玩性」

## 所有者的长期口味（违反任何一条都要在评审里指出）

- **玩得爽第一**：少重复、多惊喜；遇敌只降不升；降遇敌后用剧情/训练家/Boss 奖励补经验，不逼人刷。
- **核心信息一眼可见**：首屏不滚动，不堆数字，能用图标不用文字；浮层只放玩家打开它要看的东西。
- **该做的事要被告知**：可领奖励、新条目都要红点和一次性引导，不能靠玩家偶然发现。
- **数据不硬编码**：所有数值、文本都在 `content/**/*.json`，经 `t()` 取文本。
- **角色保持 2D 像素**，不做 3D/视频。

## 文案红线

- 不用真人姓名或外号；不骂人；不拿真实死亡、灾难、受保护群体开玩笑；
- 未经证实的说法写"据说"；
- 风控/封号只当玄学梗，不写规避教程；
- 梗的来源是贴吧、linux.do 社区（ChatGPT=酱汁，Opus=拒绝国内，Grok=偷代码，OpenClaw=安全）。

3. **对 §9 D1–D8 的意见**：每项选 A/B/C 或提出修改版，一句理由。
4. **M1 必须改的点**：只列会影响 M1（新序章、DeepSeek 引导战、Lv1 签约、随机属性、存档 v2）实现的条目。
