# 0003 评审：剧情策划

评审对象 `docs/design/0003-story-and-progression.md`（#41）。行号 `0003:N` 指该文件；其余为仓库路径。`[verified]` 为读过源文件或跑过脚本，`[unverified]` 为假设，需实测。

## 结论先行

1. **Crosery:** 45–53 分钟进 Boss 战不算"快速"。剧情层面可把序章 18 拍压成 11 拍：新手 **目标 30、验收中位 ≤32 分钟进战，≤43 分钟拿到 V4 卡**（现稿 45 / 56），熟练 ≤18 分钟。慢在站点（8→5）和战斗（7–8→5），不在对白字数（单搭档路径 95 句，约 5 分钟）。
2. 序章现在是"讲课 + 差事"：同一条峰谷规则战前战中被讲 **27 次**，博士 20 句里 ≥10 句在做说明，三项"上岗清单"差事没有世界内理由。改成"先演出、讲解极简、玩家动手"，同一规则最多讲 3 次。
3. 17 个 Boss 的 6 段模板已使 ≥10 个 Boss 同构（打听 → NPC 给 ×2 反制道具 → 上），副本三段形也同质；除 V4、小 R 外，Boss 少女没有"想要"，台词都是梗的自我陈述。用"剧情形状 + 想要"表打破（§4.2），重写最弱三个：Seedance、Grok、Mythos。
4. **红线要热修，不等 M4：** `items.json:37-38` 的「纯净住宅 IP」「苹果订阅」与 0003 §7.14 的四栏计量条是现实规避手段的 1:1 映射，而 `0003:1352` 只担保"台词"干净。
5. 人物：小 R 有口癖没有弱点；零没有动机，且零与玩家各拿一张千问，"放下说明书"无因果；V4 摸鱼没有同情点。给出三条弧光（§3）和 7 个跨章惊喜（§4.4）。
6. 对 §9：D1 选 A（改：以"上岗证"做世界内门禁）；D2 选 A（要求每个 Boss 一句专属签约台词）；D8 选 A（把 Cursor 前移填第一章空白）。

## 1 问题清单

### 阻断

**P1 到 Boss 的时长不是"快速"**
- 现象：进战 45–53 分钟（`0003:105-106`），验收中位 ≤48（`0003:1310`）；进战前 7–8 场战斗、约 8 次停靠换图。
- 证据：节拍 18 个（`0003:160-179`）；附录 A 单搭档路径 95 句，含变体 112 句 / 3216 字，按 3 秒一句只有约 5 分钟 [verified，脚本见 §9]。
- 改法：§2 的 11 拍方案；验收改为"新手中位 ≤32 分钟进战（目标 30），熟练 ≤18 分钟，V4 入队 ≤43 分钟"。

**P2 序章是"讲课 + 差事"，不是"边玩边学"**
- 现象：峰谷规则（高峰忍、谷时上）战前 14 句、陪练 3 句、战中教练 10 句，共 27 句；另有 5 处环境暗示。博士 20 句里 p2–p7、p13–p15、p17–p18 共 10 句是说明（`0003:1464-1470,1482-1484,1599-1600`）。
- 证据：§3.3.1 的"六层"（`0003:191-202`）里第 1、2 层已把规则演完，第 3、4、5、6 层又各讲一遍。`lobby.b2-b6` 五句连续复述（`0003:1541-1545`）。p13 在玩家动手前就把机制剧透完（`0003:1482`）。
- 改法：规则只讲三次——环境（保安 + 公告屏）、演出（零被拍回）、一次简报（≤5 句，小 R 口癖）；其余交给陪练演示和 3 条教练。改写见 §5.2。

**P3 规避风控：现实手段被做成了道具（M4 前必改，已上线部分建议现在热修）**
- 证据：`0003:896` 旅店老板塞"纯净住宅 IP、苹果订阅各 1"；`content/items.json:37-38` 的描述写"机房 IP 一用一个准""Apple 当中间人，风控看不到你的卡"；`content/text/zh-CN/boss.json` 的 `opus.gossip1/cloak/paid/warn_pay/warn_region`。四栏（支付/地区/行为/共享）+ 对应反制 = 一张规避速查表。`0003:1352` 只担保"台词"，没提道具与计量条映射。
- 改法：道具改成纯虚构，保留 id 不动存档：`residential-ip` → 「平安符·地区」，`apple-sub` → 「平安符·支付」；描述统一为"纯属玄学：贴上之后，风控的『地区』栏暂时不涨。游戏道具，别当真。"；`warn_pay` 的括号改"（据说支付栏最敏感）"，删 `warn_region` 里"纯净住宅 IP 能稳住"；`gossip1` 删"虚拟卡、野卡""Apple 当中间人"。

### 重要

**P4 零没有动机，千问线自相矛盾**
- 现象：零在新稿里三次都是反面教材——碰壁（`0003:1506-1511`）、囤邀请码（`0003:742`）、抄说明书（`0003:929-934`）；他对玩家取胜的反应只有"哈！"（`0003:1603`）。
- 证据：①第五章零亮出千问卡（`0003:866`），第七章玩家又去打千问 Boss 拿一张（`0003:925-934`），"同一个人"有两份；②既有设定被忽略：`content/world/story/npcs/hidden.json` 的 `zero-keeper` 写明"零"是第 0 号服务器的缩写、零一直在找名字来历，`rival-frost` 也已说过"变强是为了保护想保护的东西"。
- 改法：见 §3 零的四拍弧光；千问卡改成"蒸馏版"，由 Boss 千问送出，第七章零放生它，因果自洽。

**P5 6 段模板使 Boss 同构**
- 现象：§7.1 六段（`0003:641-655`）+ §4.1 的前厅 / 关卡 / Boss 房三段（`0003:333-355`）+ 每个 §7.x 的"场景 3 条 / 教学 / 回报 / 台词 2 条"版式。
- 证据：17 个里 ≥10 个是"NPC 打听 → 拿到专用反制道具 → 开打"：半价券、邀请码 ×3、投诉信 ×2、私有题库 ×2、网线、.map ×2、小石子 ×2、香蕉皮、IP/订阅、吊销密钥 ×2（`0003:737,766,783,801,818,850,865,896,915`，另有 DeepSeek 的半价券）[verified]。世界替玩家解完谜，玩家只剩执行。
- 改法：每个 Boss 一个"剧情形状"和一个"想要"（§4.2）；至少 5 个副本不用三段形（摄影棚、擂台、申诉庭、棋院、封存库）；"NPC 白送道具"限 ≤5 个 Boss，其余让玩家自己观察（Seedance 的 HUD、阿尔法的读招）。

**P6 Boss 少女没有人格**
- 证据：`content/text/zh-CN/boss.json` 各 Boss 的 `taunt1` 全是"第一人称自曝梗"（豆包 1.66、Cursor 按量计费、Grok 打包 .env、OpenClaw 开公网端口）。`0003:83` 支柱 4 说"Boss 少女是主角"，实际只有 V4 和小 R 有多句台词。
- 改法：§4.2 每人一句"想要"和一句专属签约台词，键 `boss.<id>.contract`。

**P7 节拍顺序与差事感**
- 现象：博士让玩家先去上属性课（B5），零的失败（B6）发生在课之后，课没有动机（`0003:1481` 的 p12 自己承认"等他上来你就知道为什么了"）。零碰壁是零转述，不是演出。
- 证据：`0003:168` B6 只有对白；`0003:1484` 清单"收服一只、去商店、去补给站"，玩家完全可以直接走下楼梯——零就下去了，凭什么玩家不行？`entry.requires ds:called`（`0003:1042`）只是规则，没有世界内理由。
- 改法：清单改成"上岗证"集章：研究所机房入口由保安大叔查证，零有博士给的通行钥匙，玩家没有——这顺带给零一层"博士身边的孩子"的底色（`0003:1480` p11 "唉，这孩子"）。B6 改成演出：楼梯口一声闷响，零被拍飞回一楼。

**P8 签约与出发 15 句里夹着系统讲解 + 串音**
- 证据：`signed.s4`（`0003:1589`）是小 R 的"让我想想"口吻，却在 V4 段；`s8`（`0003:1593`）前半 V4（"本来就没上班"）后半小 R（"我最擅长想太多"）。`s5`（`0003:1590`）"这就是大家说的『凹属性』"是玩家黑话。`p17-p18`（`0003:1599-1600`）一口气讲带教 + 许可 + 储备三套系统。
- 改法：见 §5.2 第 5–7 条。

**P9 跟随台词只有 3 条**
- 证据：`follower.v4Day/Night/Capped`（`0003:1607-1609`，`0003:717` 同样只列 3 条），而支柱 4 说"随时间和许可变化"（`0003:83`）。3 条会在第 2 章就腻。
- 改法：跟随台词做成"同伴互评"，每签约一个 Boss，V4 和已在队的卡各补 1 条对她的评价（16 条一句话即可）；另加 `ds:approach` 回响（§3 V4）。

**P10 章节仍是徽章计数器的变种**
- 证据：§2.3（`0003:112-124`）每章都是"N 号道路 → 某镇 → 道馆 → Boss → 零"，第一章没有 Boss（`0003:115`）。V4 带教追等级后，首馆被横扫（`0003:314`），第一章是全篇最空的一段。
- 改法：§6 章节表；Cursor 前移到第一章。

**P11 Mythos 终局单薄，最弱三个见 §4.3**
- 证据：§7.19 只有 3 条场景，没有选择、没有 Boss 少女的回收（`0003:973-986`）。`boss.json` 里 Mythos 自己的钩子"Discord 里已经有人用上我了"（`mythos.enrageStart`）比 §7.19 的任何一条都有戏，却只埋在狂暴台词里。

### 建议

### 4.3 最弱三个的重写方向

**Seedance（`0003:744-759`）**

**Grok（`0003:796-811`）**
- 现象：行商卖网线 = 把解法卖给玩家；三个 NPC 全是信息柜台；Boss 只有一句"不介意吧"。

**Mythos（`0003:973-986`）**
- 现象：终局只有 3 条场景，无选择、无回收，小 R 只给数值情报。

- 次弱：GLM 与 Gemini 同属"受害者 → 友好陷阱"，与 Grok 的"信息柜台"同构，重写时一并拉开形状。

## 7 对 §9 的意见
